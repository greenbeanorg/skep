# hearst: the test installation moved to the package layout, 2026-11-15

Approved by Andy. Closes the gap left by ownership-fix.txt: the binaries,
agent.json, the install media, and skep-api's data were under /home/aba,
which aba owns, so aba could replace them. They are now where the package
puts them, every directory above them root's:

  /usr/local/sbin/skep-agent, skep-api   root:wheel 0555
  /usr/local/bin/skepctl                 root:wheel 0555
  /usr/local/etc/skep/agent.json         root:wheel 0600 (dir 0755)
  /var/db/skep/agent                     root:wheel 0700 (unchanged: the agent already used it)
  /var/db/skep/api                       skep:skep 0700 (copied from /home/aba/skep-m5/state/api)
  /var/db/skep/media                     root:wheel 0700 (copied from /home/aba/skep-m6/media)

The rc.d scripts on hearst are byte-identical to packaging/rc.d and their
defaults are exactly this layout, so rc.conf no longer overrides the
binaries, the configuration, or the data directory; only the listen
address stays (skep_api_args). agent.json is the old one with media_dir
changed from /home/aba/skep-m6/media to /var/db/skep/media. The media
move was not in the request; it was the last thing the agent read from
aba's home. /var/db/skep/api already held older (Milestone 4, Nov 12-13)
API state; it was renamed, not overwritten. Times are UTC.
