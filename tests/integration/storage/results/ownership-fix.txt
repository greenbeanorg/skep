## Not closed by this change
/home/aba is aba:aba, and it is the parent of /home/aba/skep-m6 (the
binaries and agent.json that rc.conf names: skep_agent_bin,
skep_agent_config, skep_api_bin) and of /home/aba/skep-m5 (aba:aba, which
holds skep-api's data directory state/). aba can rename either directory
and put another in its place; the next service start then runs that
skep-agent as root. Closing it needs the installation moved to a path
whose every directory is root's (for example /usr/local/libexec/skep-test
and /var/db/skep-test-api) and rc.conf pointed there: an rc.conf change,
not made without Andy's approval.
