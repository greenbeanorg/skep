== 6. A slip during the comparison, and its check ==

To compare the package databases, I first ran `pkg shell <copy>` on hearst.
pkg shell takes no database path: it opens the host's own
/var/db/pkg/local.sqlite and treated the path as SQL, which failed to parse
before anything ran. Because that touched the host's /var/db/pkg, the host
files were hashed again at once: identical to host-before.txt. The
database comparison was then done on merrick on copies.
