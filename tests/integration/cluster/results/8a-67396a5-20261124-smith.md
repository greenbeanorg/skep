## Not covered here

- The node's own key on the listener (accepted, then closed): unit-tested
  only; the probe has no access to the key, by design.
- An expired certificate, renewal, a stopped state machine, a listener
  that cannot bind: unit-tested only.
- A boot of the host with `skep_cluster` enabled: no reboot was allowed.
- ZFS-root hosts (langrishe, star): not touched in this run.
- `init` prints one library warning line ("heartbeat timeout reached,
  starting election") before its own output; harmless, cosmetic.
