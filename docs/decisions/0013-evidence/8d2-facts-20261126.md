## F2. agentproto.Caller and the drain

  `Skep-Actor-Id`, `Skep-Actor-Name` (mandatory, `^[A-Za-z0-9._:-]{1,128}$`),
  `Skep-Request-Id`, `Skep-Source-Ip`, `Idempotency-Key` (optional, set

  "skep-cluster-join"` (`cmd/skep-cluster/join.go`).
- The drain (`internal/internalapi/operations.go`, `handler.drain`;
  `internal/tasks/drain.go`): `drain-get` GET, `drain-set` POST,
  `drain-clear` DELETE on `/internal/v1/drain`; set and clear are root's
  alone (the operation table). Every answer is `DrainStatus`
  `{"reason":"join","expires_at":"<RFC 3339>","unfinished_tasks":N}`
  (`reason` and `expires_at` omitted when no drain is active).
  - POST body `{"reason":"upgrade"|"join"}`, strict; it sets the drain
    for `tasks.DrainFor` (60 s) or renews one of the same reason
    (`Engine.SetDrain`); `node.drain.set` is audited only when it was
    not active.
  - Another reason active: `409`
    `{"error":{"code":"drain_active","message":"a drain with another reason is active; nothing was changed","details":{"reason":"upgrade","expires_at":"..."},"request_id":"..."}}`
    (`httpkit.Fail` writes the details; `models.CodeDrainActive` → 409
    in `internal/httpkit/fail.go`).
  - DELETE clears **whatever drain is active, of any reason**
    (`Engine.ClearDrain`), audits `node.drain.cleared`, and answers the
    state after it. **(used: the join clears only a drain it set, and a
    renewal that fails with `drain_active` is not followed by a clear;
    see "Decisions for review".)**
  - While a drain is active a new task is refused: `503`
    `{"error":{"code":"node_draining","message":"this node is draining (join): no new task is accepted until <RFC 3339>","details":{"reason":"join","expires_at":"..."}}}`
    (`drainRefusal`; `CodeNodeDraining` → 503).
  - The drain expires by the engine's clock (`activeDrainLocked`, audit
    `node.drain.expired`); an agent restart clears it.

## F7. service.JoinCall and "nothing applied"

- `service/peer.go` (`JoinCall`): an error that is not a `PeerError`
  and not an `OutcomeUnknownError` (handshake refused, unreachable) is
  "nothing sent"; a `PeerError` is an answer: `outcome_unknown` sets
  `unknown`, `refused` sets the refusal, `not_leader` follows a known
  leader, **any other code (`invalid_request`, `unavailable`,
  `forbidden`) is "nothing applied" and the next member is tried**. At
  the end: unknown → `JoinUnknown`, a refusal → `JoinRefused`, else
  `JoinUnreached`.
- An 8d-1 member decodes the join body with `strictJSON` before
  anything else (`HandlePeer`, `case raftnet.OpJoin`), so a body with
  `guests` is answered `invalid_request` by every 8d-1 member, leader or
  not. JoinCall ends `JoinUnreached`, and `stageJoin`
  (`service/stage.go`, the `default:` branch of its switch) removes
  join.json and puts the one-node state back. **(used: D15.)**
