Skep

The web interface was not built into this binary. This skep-api was compiled without the skep_webui build tag, the way go build ./... does it, so it carries this page instead of the interface.

To get the interface, build the release binaries with make build (this machine) or make build-freebsd (FreeBSD amd64) in the Skep repository. Both build the interface with Node.js first and embed it. See web/README.md.

The API is unaffected and is served under /api/v1.
